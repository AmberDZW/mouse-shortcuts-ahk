# 鼠标快捷键工具

## 三步开始

1. 下载 [MouseShortcuts-1.0.2.zip](https://github.com/AmberDZW/mouse-shortcuts-ahk/releases/download/v1.0.2/MouseShortcuts-1.0.2.zip) 并完整解压。
2. 双击 `MouseShortcuts.exe`。
3. 直接在设置窗口中选择按键和动作。

不需要安装 AutoHotkey，也不需要安装其他运行环境。不要直接在压缩包窗口中运行，请先解压整个文件夹。

默认设置：左键静止长按 2 秒启动语音输入（Win+H），拖拽会取消计时；鼠标中键也启动语音输入，侧上键发送回车，侧下键发送退格；其他扩展键显示但默认关闭。

工具支持中英文界面、五组常用文本、按键检测、冲突提示、开机启动、托盘暂停或恢复、恢复默认设置，以及配置导入导出。个人设置保存在 Windows 用户数据目录，升级程序不会覆盖。

更完整的使用与构建说明见 `README.md`。
