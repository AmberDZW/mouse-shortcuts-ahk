# Security

Mouse Shortcuts is a local-only AutoHotkey helper. It does not send data to the network and does not need administrator privileges.

## Reporting

Please open a private security advisory or contact the maintainer before publicly disclosing a vulnerability.

## Safety Notes

- Review `mouse-remap.ini` before running a shared configuration.
- Only download release archives from a maintainer-controlled page.
- AutoHotkey scripts can automate keyboard input, so avoid running modified copies from unknown sources.
